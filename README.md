# ✈️ TripGo – AI-Powered Travel Planner

TripGo is a full-stack web application that helps users create personalized travel itineraries using Artificial Intelligence.

Users can enter their destination, travel dates, budget, number of travelers, and travel style, and receive a customized day-by-day travel plan generated by AI.

---

## 🌍 Features

- ✈️ AI-generated personalized travel itineraries
- 📍 Destination selection
- 📅 Flexible travel dates
- 💰 Budget-based recommendations
- 👨‍👩‍👧 Support for solo travelers, couples, families, and groups
- 🌎 Multi-language interface
- 🗺️ Interactive travel planning experience
- 🤖 Secure server-side OpenAI integration

---

# 🏗️ Architecture

```
React Frontend
      │
      ▼
User Preferences
      │
      ▼
Express / Node.js Backend
      │
      ▼
OpenAI API
      │
      ▼
Personalized Travel Plan
```

The frontend collects the user's travel preferences and sends them to the backend. The backend securely communicates with the OpenAI API and returns a structured itinerary to the client.

# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/taliawachter/TripGo.git
cd TripGo
```

## Install frontend dependencies

```bash
npm install
```

## Install backend dependencies

```bash
cd server
npm install
```

## Configure environment variables

Create a `.env` file inside the `server` directory.

Example:

```env
OPENAI_API_KEY=your_openai_api_key
PORT=3001
```

## Run the backend

```bash
cd server
npm start
```

## Run the frontend

```bash
npm run dev
```

---

# 🔒 Security

- OpenAI API keys are stored only in server-side environment variables.
- Sensitive configuration files are excluded from Git.
- API communication is handled through the backend to keep credentials secure.
